Dashboard Guide

This page explains how the admin dashboard maps to runtime behavior.

1) Provider & Account Operations

Providers
Enable/disable providers, view health/latency, and routing availability.
Accounts
Manage multiple keys/tokens per provider, with cooldown and quota tracking.
Routing Rules
Per-model provider order/weights/strategy for fallback orchestration.
Metrics
Requests, retries, fallback events, queue pressure, latency, and costs.

2) OAuth Ecosystems

Use Connect Google and Connect GitHub for OAuth onboarding. Tokens are stored encrypted and used by provider pools.

Flow: click connect -> consent -> callback -> account appears -> eligible for routing.

3) Agents Control Center

  • Rescan/import all discovered skills
  • Role-level on/off toggles
  • Sub-agent-level on/off toggles
  • Sync enabled agents to Claude directory (~/.claude/agents or configured target)

4) How It Connects To Claude Code

fcc-claude points Claude CLI to the local gateway URL and auth token. Claude continues to use Anthropic-compatible endpoints, while the gateway chooses providers/accounts.

5) Recommended Operator Workflow

  1. Start fcc-server
  2. Configure providers/accounts in dashboard
  3. Set routing strategy and fallback chain
  4. Import/rescan/sync agents
  5. Run fcc-claude from your project folder
